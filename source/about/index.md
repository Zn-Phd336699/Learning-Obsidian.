## 关于本站

这是一个**嵌入式软件开发知识库**，系统整理从裸机到Linux的全栈学习笔记。

## 内容覆盖

| 篇章 | 内容 |
|------|------|
| P1 编程基础 | C/C++/汇编/链接器/MISRA/单元测试 |
| P2 调试工具链 | GCC/GDB/OpenOCD/示波器/逻辑分析仪/Wireshark |
| P3 单片机开发 | Cortex-M架构/STM32外设/DMA/低功耗/OTA |
| P4 SoC开发 | ARM-A架构/RK全系/Buildroot/Yocto/NPU |
| P5 RTOS | FreeRTOS/RT-Thread/Zephyr/seL4/reL4 |
| P6 嵌入式Linux | 驱动开发/rootfs/epoll/性能优化 |
| P7 Android底层 | AOSP编译/init/Zygote/Binder/OTA |
| P8 协议开发 | UART/I2C/SPI/CAN/USB/lwIP/MQTT |
| P9 项目集 | STM32监测终端/ESP32信息站/LoRa网关 |
| P10 安全量产 | Secure Boot/密钥管理/HIL台架 |
| P11 工程算法 | 滤波/卡尔曼/PID/SVPWM/CRC/FFT |
| P12 性能工程 | USE方法/火焰图/MCU优化/RTOS调优 |
| P13 ZYNQ异构 | PS+PL架构/Verilog/Vivado/AXI协同 |

## 技术栈

- **MCU**: STM32, ESP32, GD32
- **SoC**: RK3588, i.MX6ULL, ZYNQ7020
- **系统**: FreeRTOS, RT-Thread, Zephyr, seL4, Linux
- **语言**: C, C++, Rust, Python, Verilog
- **工具**: GCC, GDB, OpenOCD, J-Link, CMake, Vivado

## 建站方案

- **知识库**: Obsidian + Git 私有仓库
- **博客引擎**: Hexo + Butterfly 主题
- **部署**: GitHub Pages + GitHub Actions 自动化
- **同步**: 自研 Obsidian→Hexo 同步脚本，自动转换Wiki链接和Callout
